# Employee Management Using Python

A command-line employee manager that stores records in `employees.json` beside
the application file.

## Run

```powershell
python employee_management.py
```

Choose an option to add, update, delete, or view employee records. Each employee
has an ID, name, age, department, and salary. Employee IDs must be unique.

## Run tests

```powershell
python -m unittest -v
```
